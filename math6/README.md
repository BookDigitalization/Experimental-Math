# 中学数学实验教材 第六册（上、下册）

本项目对1980年代出版发行的《中学数学实验教材 第六册》进行了重排。

这一套中学数学实验教材是教育部委托北京师范大学、中国科学院数学研究所、人民教育出版社、北京师范学院、北京景山学校等单位组成的领导小组组织“中学数学实验教材编写组”，根据美国加州大学伯克利分校数学系项武义教授的《关于中学实验数学教材的设想》编写的。

本重排本将原教材的上下两册合排成一本（`main.tex`），`main - 6A.tex` 和 `main - 6B.tex` 分别是拆分后的上、下两册。与其他各册不同，第六册上、下两册在原书中**各自从第一章开始编号**，合订本沿用这一编号方式，以“第六册（上）”“第六册（下）”两个部分分隔。源文件对应关系如下：

| 文件 | 内容 |
|---|---|
| `1.tex` ~ `3.tex` | 上册 第一章 ~ 第三章 |
| `app.tex` | 上册 附录：统计学简介 |
| `4.tex` ~ `7.tex` | 下册 第一章 ~ 第四章 |

说明：

- 上册：经过初步校对，原铅字版错误之处甚多（几乎每页都有，尤其是上下标和字母错误）。网上流传的第六册（上）有 2000 年前后重新整理排印的版本，内容安排与前几册有重叠之处，阅读时请注意甄别。
- 书中的矢量图片使用 TikZ、tkz-euclide 和 CircuiTikZ 制作。
- 书中的内容仅供参考，相当一部分内容已经超纲，请仔细辨别。

**注意：本项目的内容勿用于商业目的。**
